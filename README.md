# Tempo — Stopwatch
A beginner project made with HTML, CSS, and JavaScript.

## Run
Extract the ZIP and double-click index.html. No installation needed.
Or open this folder in VS Code and use Live Server.

## Features
- Start, pause, resume, and reset.
- Lap durations and cumulative elapsed time.
- Responsive purple design.
- Runs offline with no dependencies.

## Files
- index.html: page structure.
- style.css: colors and responsive layout.
- script.js: timing and button behavior.

The stopwatch uses performance.now() to calculate elapsed time accurately while the page remains open. Refreshing or closing the page resets it. It is intended as a learning project, not a precision measurement instrument.
